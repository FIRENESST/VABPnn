# 连续显存管线 0.6.0

本模组在 Minecraft 26.1 最终 blitToScreen 后、swap 前复制默认 back buffer。游戏默认帧缓冲只作为读源；输出到自有 RGBA8 FBO 纹理。复制及 GL 栅栏提交在渲染线程，CUDA 所有权在共享 WGL 后台线程。

## 所有权与有界池

纹理状态：FREE → WRITING → PENDING → COPYING → FREE。
线性帧状态：FREE → COPYING → READY → PROCESSING → FREE。

默认各 4 槽。完成 GL 栅栏后才 map；D2D 复制后 unmap，CUDA copy event 完成才将纹理归还渲染线程。worker 消费最新 READY 帧，丢弃旧 READY 帧；绝不回收 COPYING 或 PROCESSING 帧。

每个线性帧有 pitched RGBA8 与 RGB float32 NCHW。示范元数据在提交时与纹理一起发布、随复制附到对应帧，避免 GPU 拥塞时取到另一帧的输入状态。

尺寸变化先退休池，后台排空事件与 CUDA 工作，释放旧注册和槽，再创建新池；渲染线程轮询状态，不等待 CUDA。模型和 AdamW 状态保留。

## 每次消费的同流顺序

1. 上传对应帧的少量真实输入累计量。
2. 用前一观察的独立 GPU 缓存及新到输入，训练前一观察的像素、贝叶斯输出头、k、鼠标和滚轮头。
3. 当前 RGBA8 → 左上原点 RGB NCHW；固定 1920×1024 网格执行 sign RGB 三值加权和，全画面整数累加。
4. JEPA 重编码过去的 patch 特征，预测当前 EMA 目标；编码当前表示并推理鼠标位移。
5. 滚轮头形成位移提案；时间图、连续时间马尔科夫先验、贝叶斯后验、严格学习阈值、学习 k 和四组互斥选择。
6. JEPA 自监督反向 / AdamW / EMA；把当前 RGB8 观察复制到固定 GPU 示范缓存，保存当前输入基准。
7. 异步传出最终 40 字节 ControlCommand 和少量标量训练状态；整个 operator stream 完成事件完成后才回收槽。

全部计算使用 frame.stream；其他流必须先 join 回该流。不能保留或释放帧池指针。示范缓存与 JEPA patch 缓存由模型单独持有，大小固定，无 CPU 图像链路。

## 输入与示范

默认 HUMAN；F8 切到 MODEL，F9 暂停，F10 后台保存。主机只记录真实输入。模型输入调用有 synthetic guard，MODEL 元数据也在 GPU 侧拒绝任务示范更新；模型输出不作为 BC 标签。

累计鼠标、滚轮、键盘按住时间与按钮边沿在掉帧后仍完整。新世界、模式/活动范围改变、反向时钟、输入非有限或超过 250 ms 的间隔不训练跨界样本。鼠标目标用原始单位/秒；视角/GUI 切换排除该次位移目标。

最终输入经 Minecraft 26.1 的输入回调执行。相同帧不会重复位移、滚轮或点击。失焦、暂停、死亡、退出世界和过期控制释放模型持有的输入，物理用户按住的输入不被强行释放。

## 参数与检查点

常驻模型和在线 GPU 缓存 **404,772,192 字节（约 386 MiB）**，另有帧池。原始投票参数 **76,677,120**，JEPA 含 EMA **555,650**，均保持原预算和接口。OnlineLearning 额外保存浮点潜在三值参数、少量头优化器与一帧固定 RGB8 缓存。

vabpnn/models/online-v1.bin 含三值与潜在参数、决策输出头参数、JEPA/EMA、优化器矩与步数，约 372 MiB。只保存权重，不保存图像或激活。后台每两分钟或 F10、正常退出时保存；SHA-256 完整验证后恢复，临时文件完成后原子替换。检查点期间 worker 暂停消费，渲染和有界丢帧继续。

在线学习是局部像素监督与固定图主干的输出头训练，未实现穿过硬 sign/top-k 的端到端梯度，也没有自主奖励训练或正式 LIF 脉冲机制。[模型公式、动作映射和开发方法](../README.md)
