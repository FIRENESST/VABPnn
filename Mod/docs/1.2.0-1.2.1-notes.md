# VABPnn 1.2.0 / 1.2.1 需求说明

两版只保留这份说明文档，不构建或安装独立包。功能统一随 1.3.0 交付。

## 1.2.0：冻结边界

F8 模型控制和 /vabpnn predict 仅预测模式冻结神经网络参数，包括像素三值及主权重、Transformer multihead、决策/阈值/k/坐标头、JEPA/鼠标头、块与模因策略参数，以及对应 AdamW 状态和 JEPA EMA。

高贡献点的分布、贡献与重要性统计继续随预测更新；选点和局部/长程 CSR 连接仍每五次预测刷新。膜电位、时间历史、贝叶斯概率、模因包传播继续运行。动态选点的运行统计与网络梯度学习相互独立。

仅预测模式保留不注入键鼠的约束：/vabpnn start predict 从首帧仅预测；/vabpnn predict [on|off] 切换。F8 开启模型控制，再按恢复人工示范。

## 1.2.1：连续执行

F8 持续生成新的预测包并交给原 Minecraft 输入执行路径。所有数值有效的动作进入后验排序，不再由“置信度是否超过阈值”拦截。

保留网络决定的 k、后验 top-k、既有四组互斥关系、按住/释放语义和鼠标位移算子。k=0 表示本帧选择休息，也生成有效的新包；不强制随机动作。阈值仍可展示并在示范时学习，F8 和仅预测的最终候选筛选不使用阈值比较。

暂停、停止、失焦、聊天、加载及指令过期仍按已有输入上下文处理，并释放模型持有的键鼠。这些限制与动作概率阈值无关。

## 合入 1.3.0

以上要求全部进入 1.3.0；另外增加绕过脉冲门控的候选点探测、按贡献反馈更新的位置价值、探索与空间覆盖。1.2.0 和 1.2.1 无单独 jar、DLL 或模型保存路径。
