# 1.4.0：图 Transformer 的秒 / 分钟双时间轴

## 同时推进的两个尺度

秒轴保留原有 8 帧图注意力、秒时间编码、CTMC 转移和贝叶斯先验。分钟轴每帧并行计算，输入包含当前 15 项原始投票和显存中的分钟投票摘要；使用独立频率、时间编码和按分钟计的注意力衰减。它不是把原 8 帧的时间简单改名。

分钟缓存为当前分钟及前 7 个分钟槽。槽内使用相邻实际观察的间隔加权平均投票，每个间隔最多记 0.25 秒；新槽第一样本按 1/30 秒计。同时间戳不重复累计。断档没有观测的分钟不造样本，不把断档当成画面持续不变；超过 8 分钟窗口的槽淘汰。历史摘要每帧重新使用当前参数计算 K/V，学习后不会沿用旧投影。

一分钟以内也能预测和训练；跨过 60 秒边界，新的分钟槽才追加。历史与原秒轴一样，在世界和模式复位、倒退时钟时清空；模型参数和优化器不重置。

## 训练与融合

分钟分支宽度 8、2 个头，共 1,117 个参数。当前投票产生查询，所有已观察分钟中的 15 个对象产生键和值；图偏置与分钟衰减决定因果注意力。注意力输出与当前编码残差经 tanh 后，分别形成额外条件对数似然比和 k logits。

额外证据加到原秒模型和坐标支路的证据上，再用原 CTMC 先验做贝叶斯计算。分钟 k logits 加到原 k 头，继续按后验 top-k 和既有互斥规则选对象。F8 / 仅预测仍取消置信度阈值拦截，k=0 保留为模型休息选择。

监督来自原有真实人工操作接口：当前输入标签对应缓存的上一张观察；不会用未来投票或 XYZ 更新旧帧，也不拿模型预测充当示范。AdamW（学习率 0.0003）优化动作 BCE + k 交叉熵，梯度包括分钟 Q/K/V、图偏置、时间编码、频率、衰减和两个融合头，也包括 k 经后验与软阈值回到分钟证据的路径。CTMC 先验作为该步固定状态，不宣称跨无限历史反向传播。

新增融合头初始为零，旧模型迁移后行为由已有秒分支决定。编码器/注意力初始化非零，融合头得到真实示范后，梯度继续流到分钟注意力。已有 100,000+ 示例不等于新分钟分支已训练，需要继续给出真实示范，尤其是跨分钟的重复情境。

## 贝叶斯条件下的 JEPA 鼠标位移

鼠标位移也使用当前帧的贝叶斯结果。新增 66 参数的残差头，输入为 15 个对象的后验、先验、JEPA 未融合的 X/Y 速率及偏置；输出为归一化速率修正。融合后的 X/Y = 原 JEPA 速率 + 修正 × 原速度上限，然后沿用原单帧时间、1200 单位/秒、32 单位/帧上限以及 X/Y 对象的执行允许。不会固定乘上一个小于 1 的置信度来缩小所有鼠标运动。

残差权重初始为零，旧 JEPA 数值保持不变。有效真实鼠标示范通过独立 AdamW 和归一化 MSE 训练残差；缓存使用上一张观察的后验/先验与 JEPA 原速率，指针模式切换、失焦、过期/失效帧不学习。JEPA 原位移头的学习保留，贝叶斯残差另用 66 个权重及 800 字节持久状态，随分钟权重一起加入新 checkpoint part。F8 和仅预测冻结全部残差权重/矩/步数。

分钟证据影响贝叶斯后验，后验又影响这个鼠标残差，因此分钟上下文也能影响最终鼠标位移。没有用随机动作或模型输出替代人工位移目标。

## 模式和存档

- 人工示范：原学习器与分钟 AdamW 一起学习，无模型键鼠注入。
- F8 连续操作：全部神经网络 / multihead、AdamW、EMA 冻结；分钟缓存和动态高贡献点 / 选点 / CSR 推进，执行新预测包。
- 仅预测：与 F8 的冻结范围一致，无模型操作注入。
- `/vabpnn status`：显示秒 / 分钟时间、已观察分钟槽数、分钟注意力训练步数。

分钟状态单独追加为 v8 / VABPNND 第 19 个 checkpoint part，大小 14,216 字节，包含分钟与贝叶斯鼠标参数、各自的两个 AdamW 矩和步数；原 v7 的前 18 个部分没有变更。完整文件大小 522,109,692 字节。先加载 release-1.4.0.bin，不存在则只读继承 release-1.3.0.bin，再走原 v6 / 13 操作历史迁移。保存只写本版模型，历史版本不覆盖。图像仍全在 GPU，不落盘。

## 验证范围

新增独立双精度 CPU 注意力参考和所有 1,117 项参数的中心差分梯度校验，验证梯度、分钟衰减、跨秒缓存的历史影响、时间边界 / 缺口 / 重复时间戳、冻结 / 解冻 / 失效帧，以及 v8 哈希和优化器恢复。原 GPU / JNI / Minecraft 回归与每帧 10ms 预算检查随本版执行。分钟压测先填满 8 个已观察槽，避免仅测单槽；GPU 链预算不包含 Minecraft 渲染、GL blit/map、初始化或存档。

### 1.4.0 验证结果

16 组 CUDA 验证通过。分钟轴全部 1,117 项参数经独立双精度中心差分核对，最大绝对误差 8.92e-8；其中 1,112 项在不对称测试情境下为非零梯度。时间频率、分钟衰减、Q/K 和两个融合头均实际更新，8 帧秒缓存滚动后旧分钟仍影响结果。贝叶斯鼠标全部 66 项真实目标梯度、零初始化兼容、X/Y 独立条件化、放大 / 缩小和速度上限通过。

GPU 哈希验证分钟与贝叶斯鼠标的权重、AdamW 矩和步数在 F8 / 仅预测保持不变，回到示范后恢复学习；高贡献点、候选位置价值与 CSR 照常动态更新。窗口/UI、MSAA 0/4 的真实 GL/JNI、用户 release-1.3.0.bin 的只读继承与 v8 冷恢复通过，源模型 SHA256 未变。Minecraft 26.1 临时世界验证了实际聊天时间状态、冷启动仅预测、两个新训练步数的冻结、连续操作、全部 15 路输入、背包鼠标、Ctrl/Shift、暂停 / 退出 / 存档。

GPU 空闲（4 MiB / 0%，无其他计算进程）开始的满 8 分钟槽压力测试：RTX 5070 Laptop、Release/O3、1920×1024；每档 64 帧预热 + 512 帧测量，成熟模因、F6 5Hz 采样、F7 采样均启用，最重档每帧 Scope / 排名 / 变异也计入。
